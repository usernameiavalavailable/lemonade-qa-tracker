# Lemonade Prompt Timer

Install: chrome://extensions -> Developer mode -> Load unpacked -> select this folder -> reload lemonade.gg.

A small draggable pill shows: [Hide map] ● ⏱ time · credits · turns [Copy]

Copy produces:

"your prompt"

Model Name
Cost: 0
Turns: 13
Time: ~ 4:37

Alt+M also toggles the map. Turns = tool calls (an "Investigating (N tools)" group counts as N).

## Feedback form
Click **Feedback** on the pill. Fields follow the team guidelines (detail, expected vs actual, your thoughts,
project URL, screenshots/video) with a live ✓ checklist. **Copy feedback** puts a Discord-ready message on the clipboard
(optionally including model · cost · turns · time of your last prompt). Your draft is saved between reloads.
